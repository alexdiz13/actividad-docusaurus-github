# Análisis de requisitos

En esta fase se identifican las necesidades que debe cubrir la aplicación de gestión de tareas.

## Requisitos funcionales

- RF1: El usuario podrá crear una tarea.
- RF2: El usuario podrá consultar las tareas existentes.
- RF3: El usuario podrá marcar una tarea como completada.
- RF4: El usuario podrá eliminar una tarea.

## Requisitos no funcionales

- RNF1: La aplicación tendrá una interfaz sencilla.
- RNF2: La información deberá mostrarse de forma clara.
- RNF3: La aplicación deberá funcionar en un navegador web moderno.

## Usuarios

La aplicación está dirigida a personas que necesitan organizar sus tareas diarias.
