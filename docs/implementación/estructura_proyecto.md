# Implementación

El proyecto se organiza en diferentes carpetas para separar la documentación, el código y los recursos.

## Carpetas principales

- docs/: contiene la documentación técnica.
- src/: contiene el código fuente de la web.
- static/: almacena recursos estáticos.
- blog/: contiene las publicaciones del proyecto Docusaurus.

## Archivos principales

- docusaurus.config.ts: configura el sitio.
- package.json: define las dependencias y los comandos.
- sidebars.ts: configura la navegación lateral.

## Instalación

Para instalar las dependencias se utiliza el comando `npm install`.

Para iniciar la web en local se utiliza `npm run start`.
