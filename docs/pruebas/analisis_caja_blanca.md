# Pruebas de caja blanca

Las pruebas de caja blanca permiten comprobar el funcionamiento interno del código.

En la aplicación de gestión de tareas se pueden revisar las condiciones y los caminos que sigue el programa.

## Casos de prueba

1. Comprobar que se puede crear una tarea con un título válido.
2. Comprobar que no se acepta una tarea sin título.
3. Comprobar que una tarea puede marcarse como completada.
4. Comprobar que una tarea puede eliminarse.

## Resultado esperado

Cada operación debe ejecutarse correctamente y la aplicación debe mostrar el estado actualizado de las tareas.
